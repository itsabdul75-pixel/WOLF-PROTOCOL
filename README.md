WOLF PROTOCOL is a fitness and training platform designed to help users build discipline, track progress, improve performance, and challenge their limits. It brings workouts, fitness tracking, nutrition, social connections, and challenges together in one place.

**Version 0.1 — First Release**

The first release introduces the core WOLF PROTOCOL experience, including:

- Workout and training tracking
- Diet and nutrition section
- Body progress tracking
- Camera-based exercise verification and rep counting
- Friends and social features
- Fitness challenges and competitions
- Google Sign-In and Discord login integration
- Firebase integration for cloud-based features

Version 0.1 lays the foundation for future updates, improvements, and new features.

**Train with discipline. Connect with others. Challenge your limits.**
